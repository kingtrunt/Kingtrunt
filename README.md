# Name. Number. Knowledge.

### by Jealous

---

## What This Is

A landing page and intake form for **Name. Number. Knowledge.** — a service that uses Gematria to decode the hidden meaning in names.

This is the public-facing site where customers can:
- Learn about the service
- See sample Decode Cards
- Fill in their name, birth, and lineage details
- Pay via Stripe for a personalized report

---

## Features

- Purple + gold + cream aesthetic matching the brand
- Mobile-responsive design
- Intake form collecting:
  - Legal name, preferred name, middle name (NAME OF HONOR)
  - Mother's maiden and preferred names
  - Father's full and preferred names
  - Birth date, time, and place
  - Childhood and current addresses
- Stripe payment integration
- Session storage so form data persists through payment redirect
